## R1. 범위 — 바로 마시는 음료만
식약처 가공식품 DB 대분류 `음료류` 전체를 받고(원천 보관), 웹에는 아래 12개 중분류만 노출.

| 노출 | 제외 (물에 타서 먹어 수치가 희석량에 따라 달라짐) |
|---|---|
| 액상음료, 과·채주스, 액상차, 과·채음료, 액상커피, 탄산음료, 인삼/홍삼음료, 두유, 발효음료, 유산균음료, 탄산수, 효모음료 | 농축음료/베이스, 원두/원두분말, 고형차, 인스턴트커피, 침출차 |

⚠ 알려진 공백: 우유·가공유·특수영양식품으로 등록된 프로틴 쉐이크는 '음료류'가 아니라 빠져 있음 (예: 일부 셀렉스·하이뮨 제품). 범위 확대는 10/31 리비전 안건.

## R2. 표시 기준 — 1팩 기준, 대용량은 100ml(g)
- 포장 1개 용량 ≤ **500ml(g)** 이고 단위가 원천 기준량 단위와 같으면 → **1팩 기준** = 100ml 수치 × 용량 ÷ 100 (소수 1자리)
- 그 외(대용량·용량 없음·단위 불일치) → **100ml(g) 기준**으로만 표시하고 카드에 기준을 적는다.
- 필터는 카드에 보이는 값(위 규칙 적용값)에 건다.

## R3. 빈 값
- 원천이 빈 값이면 `null` → 화면 "정보 없음". 추정·보간 금지 (NFR-3).
- (확인 필요) 원천에서 단백질·당류가 빈 값인 경우가 0건 → 미측정이 '0'으로 들어가 있을 가능성. 이윤표 샘플 검수 때 확인.

## R4. 카페인
- 원천에 항목 없음 → `data/samples/caffeine_labels.csv` 에 제품 표시사항 값을 1팩 기준 mg 으로 입력, 약사 확인(`checked_by`) 후 반영.

## R5. 신규(NEW)
- 직전 수집일에 없던 식품코드. 첫 수집(2026-10-12)은 원천의 가장 최근 등록일(2026-08-31)로부터 30일 이내 등록 제품.

| 필터 | 선택지 | 정보 없는 제품 |

## 프리셋 (FR-6) — 필터 조합의 바로가기, 이름은 숫자로만
단백질 10g↑·당류 0g / 단백질 20g↑ / 탄산·당류 0g / 두유·단백질 10g↑ / 카페인 50mg 초과
화면에 "프리셋은 필터 조합입니다. 추천이 아닙니다." 고정 표시.

## 정렬
최근 등록순(기본) / 이름순. **수치 크기순 정렬은 순위로 읽힐 수 있어 넣지 않음** (§7-1).

## 표현 기준 — ⚠ 확인 필요
"제로", "고단백", "무당" 같은 말은 화면에 쓰지 않는다. 법적 영양강조표시 기준(100ml당)과 우리 기준(1팩)이 달라 오해 소지. 10/17 규제 메모에서 확정 전까지 숫자로만 표현.

## 제품 이미지 (10/12 결정: B안)
- 제조사 공개 이미지에서 배경만 제거. `data/images/sources.csv` 에 `food_cd, source_url, collected_at` 기록 → 자동 처리 (`scripts/images.py`).
- 행을 지우면 다음 실행 때 웹에서도 내려감 → 요청 시 즉시 삭제 가능.
- ⚠ 저작권: 허락 없는 사용은 문제가 될 수 있음. **10/17 규제 메모에 '제품 이미지 사용 범위' 항목 추가 요청** (이윤표).
- 이미지 없는 제품은 포장 형태 일러스트(캔/페트/팩/파우치, 장식용) + "제품 사진 준비 중" 문구.

## 금지 (§7)
- 등급·점수·순위 산출 및 노출, "추천", 별점·1위 배지, 수치 크기순 정렬
- 질병·효능 표현
- 수치 크기에 따른 색 강조(좋음/나쁨 암시) — 모든 수치 같은 색
