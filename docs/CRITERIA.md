## 표현 기준 — ⚠ 확인 필요
"제로", "고단백", "무당" 같은 말은 화면에서 **필터 조건 이름으로만** 쓰고, 법적 강조표시 기준과 맞는지 이윤표 확인 전에는 쓰지 않는다.
- (추정) 식품 등의 표시기준의 영양강조표시(무·저·고) 기준이 100ml(g)당 수치로 정해져 있음 → 우리 기본값(1팩)과 기준 단위가 다를 수 있음. 10/17 규제 메모에서 확정.

## 제품 이미지 (10/12 결정: B안)
- 제조사 공식 이미지에서 배경만 제거해 사용. 원본은 `data/images/source/`, 결과는 `data/images/cutout/`.
- 이미지마다 `data/images/sources.csv`에 `food_cd, source_url, collected_at` 기록 → 요청 시 즉시 교체·삭제.
- ⚠ 저작권: 허락 없는 사용은 문제가 될 수 있음. **10/17 규제 메모에 '제품 이미지 사용 범위' 항목 추가 요청** (이윤표).
- 이미지 없는 제품은 포장 형태 실루엣(캔/페트/팩/쉐이크)으로 표시.
